# Bunny Finance
Bunny Finance es un proyecto desarrollado como trabajo de tesis, cuyo objetivo es explorar y demostrar la implementación de un sistema financiero digital mediante tecnologías modernas de desarrollo de software, poniendo énfasis en la arquitectura, el manejo de datos y la interacción con el usuario.

El proyecto busca servir tanto como una herramienta funcional como un caso de estudio académico sobre el diseño y desarrollo de aplicaciones financieras.
